# PDF Chunk Parity And Page Selection Fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make PDF chunk lists match note chunk lists 100%, and make manual PDF source boxes/text extraction use PDF page regions instead of viewport regions.

**Architecture:** Add a shared reorderable chunk list contract above `SharedChunkCard`, add persistent extracted chunk ordering, and move PDF source rects to normalized page coordinates. Manual PDF selection and source box painting move into `pdfrx` page overlays; region text uses `loadStructuredText()` fragment bounds with cropped OCR fallback.

**Tech Stack:** Flutter, pdfrx 2.2.24, ObjectBox, existing `KnowledgeDocumentRepository`, existing note chunk editor screens, Ubuntu/proot Flutter test/analyze commands.
